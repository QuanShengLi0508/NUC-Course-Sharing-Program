----------Installation procedure for Tanner Tools V13----------------

Guys!! good news, i made it work finally. Firstly, don`t panic coz the softwares is working fine. Follow the steps

[NOTE: This is for Vista, it holds good for XP as well)

A) Once you install Tanner with 'local license' selection, paste the TannerTools_13_Corrector.exe (run as administrator for safety) in /Program Files/Tanner EDA (as directed in the text file) and run that.  ---> don`t paste it in Tanner Tools V13.0 folder, paste it in Tanner EDA folder, so you must have three files a)Tanner ToolsV13.0 b)Utilities and c)TannerTools_13_Corrector.exe in the Tanner EDA folder.

B) Don`t open TannerTools_13_Calculator until i say so.

C) Go to start>All programs>Tanner EDA>Tanner-Tools v13>L-Edit v13

D) You will get license error---> in the error window, look out for ETH ID: ---->its like 10-3C3D1.

E)Copy the ETH ID and paste it somewhere, like notepad.

F) Now run the TannerTools_13_Calculator.exe and enter the ETH-ID (all in caps including '-' , for example 10-3C3D1)

G) you will get a "lservrc" file in the same folder (atleast 9.6KB in size).

H) Copy that and paste it in the places as mentioned in the .txt file in LEGEND folder. NOTE: don`t paste it in "Program Files\Tanner EDA\Tanner Tools v13.0\legacy" coz its not necessary.

I) Now is the important step : right click on "My Computer" and click on 'properties' , in the 'system properties' go to 'Advanced' and click on 'Environment Variable'.

J) In the 'user variables' (top part) click on 'New...' and type 'Variable Name' as 'LSERVRC' (without single quotes) and in the 'Variable Value' field -->type the location of the 'lscrvrc' file ( for example C:\Program Files\Tanner EDA\Tanner Tools v13.0\lservrc )

Thats it, Enjoy the Legendary work done by LEGEND team!!
